# VanBotJS 安装脚本上传网站指南

把 `install.sh` 上传到你的网站后，用户只需一条命令即可完成安装：

```bash
curl -fsSL https://你的域名/install_vanbot.sh | bash
```

---

## 一、准备工作

确保你有：
- 网站服务器的 SSH 登录权限（用户名、密码或密钥）
- 网站根目录路径（常见：`/var/www/html/`、`/www/wwwroot/你的域名/`）
- 本地已生成好的 `install.sh` 文件（在项目根目录）

---

## 二、方式一：SCP 上传（推荐，最简单）

在**本地电脑**的终端（PowerShell / CMD / Terminal）执行：

### 1. 上传 install.sh 到网站根目录

```bash
# 语法：scp 本地文件路径 用户名@服务器IP:网站目录/目标文件名
scp install.sh root@你的服务器IP:/var/www/html/install_vanbot.sh
```

> 如果你的 SSH 端口不是 22，加 `-P 端口号`：
> ```bash
> scp -P 2222 install.sh root@你的服务器IP:/var/www/html/install_vanbot.sh
> ```

### 2. SSH 登录服务器设置权限

```bash
ssh root@你的服务器IP
```

登录后执行：

```bash
# 进入网站根目录（按你的实际路径修改）
cd /var/www/html

# 设置脚本可执行权限
chmod +x install_vanbot.sh

# 确认文件存在且内容正确
ls -la install_vanbot.sh
head -5 install_vanbot.sh
```

### 3. 验证能否通过网页访问

在浏览器打开：
```
https://你的域名/install_vanbot.sh
```

如果能看到脚本内容（或自动下载），说明上传成功。

---

## 三、方式二：SFTP 上传（图形化，适合新手）

用 FileZilla、WinSCP、Xftp 等工具：

1. 打开 SFTP 客户端，新建连接：
   - 协议：SFTP
   - 主机：你的服务器 IP
   - 端口：22（或你的 SSH 端口）
   - 用户名：root（或你的用户名）
   - 密码：你的服务器密码

2. 连接成功后，左侧找到本地的 `install.sh`
3. 右侧进入网站根目录（如 `/var/www/html/`）
4. 把 `install.sh` 拖到右侧，重命名为 `install_vanbot.sh`
5. 右键文件 → 权限 → 勾选"执行"（或 chmod 755）

---

## 四、方式三：在服务器上直接创建（不用上传）

如果脚本内容不长，可以 SSH 登录后直接创建：

```bash
ssh root@你的服务器IP
cd /var/www/html
cat > install_vanbot.sh <<'SCRIPT_EOF'
# 这里粘贴 install.sh 的全部内容
SCRIPT_EOF
chmod +x install_vanbot.sh
```

---

## 五、宝塔面板用户（最简单）

如果你的服务器装了宝塔面板：

1. 登录宝塔面板 → 文件
2. 进入网站根目录（通常是 `/www/wwwroot/你的域名/`）
3. 点击"上传"，选择本地的 `install.sh`
4. 上传后右键重命名为 `install_vanbot.sh`
5. 右键 → 权限 → 勾选"执行"（755）
6. 完成

---

## 六、修改脚本中的默认配置

上传前，可以根据需要修改 `install.sh` 顶部的配置区：

```bash
# 项目 Git 仓库地址（改成你的仓库）
REPO_URL="https://github.com/你的用户名/VanBotJS.git"

# 或者用压缩包下载（二选一，优先级更高）
TARBALL_URL="https://你的域名/VanBotJS.tar.gz"

# 安装目录
INSTALL_DIR="/opt/VanBotJS"

# npm 镜像（国内用户建议保留淘宝镜像）
NPM_REGISTRY="https://registry.npmmirror.com"
```

### 如果用压缩包方式分发

把项目打包上传到网站，用户下载更快：

```bash
# 在本地项目根目录执行
tar -czf VanBotJS.tar.gz --exclude=node_modules --exclude=.git --exclude=Van_keyword --exclude=config.json .

# 上传到网站
scp VanBotJS.tar.gz root@你的服务器IP:/var/www/html/
```

然后在 `install.sh` 里设置：
```bash
TARBALL_URL="https://你的域名/VanBotJS.tar.gz"
```

## 七、测试安装脚本

在一台干净的 Linux 服务器（或虚拟机）上测试：

```bash
curl -fsSL https://你的域名/install_vanbot.sh | bash
```

观察输出，确认：
- [ ] Node.js 正确安装（版本 >= 18）
- [ ] 项目代码正确下载
- [ ] npm install 成功
- [ ] config.json 正确生成
- [ ] systemd 服务（可选）正确安装

## 八、常见问题

### Q: curl 命令找不到？
A: 先安装 curl：`apt install curl -y` 或 `yum install curl -y`

### Q: 下载脚本时提示证书错误？
A: 网站 HTTPS 证书未配置好。可以先用 HTTP 测试，或配置好 SSL 证书。

### Q: 脚本报错 `syntax error near unexpected token`？
A: 可能是 Windows 换行符（CRLF）导致的。在服务器上执行：
```bash
sed -i 's/\r$//' /var/www/html/install_vanbot.sh
```

### Q: 想让用户指定安装目录？
A: 支持参数传递：
```bash
curl -fsSL https://你的域名/install_vanbot.sh | bash -s -- /home/vanbot
```

### Q: 想跳过交互（全自动安装）？
A: 设置环境变量跳过确认：
```bash
export REPO_URL="https://github.com/你的仓库/VanBotJS.git"
curl -fsSL https://你的域名/install_vanbot.sh | bash
```
systemd 安装的交互确认需要手动按回车，如需完全无人值守，可修改脚本去掉 read 提示。

## 九、一键命令汇总

上传后，给用户的安装命令就是：

```bash
curl -fsSL https://你的域名/install_vanbot.sh | bash
```

如果用户在国内，建议用这个（自动设置 npm 淘宝镜像，脚本已内置）：

```bash
curl -fsSL https://你的域名/install_vanbot.sh | bash
```

安装完成后启动：
```bash
cd /opt/VanBotJS
npm run dev
```
