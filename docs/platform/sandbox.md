# Sandbox（模拟环境）

> 网页访问的模拟聊天环境：在浏览器里模拟群聊 / 私聊场景发送消息，消息走完整的插件处理链路，机器人回复实时显示在网页上。适合没有真实平台账号时调试插件、验证模板标签、测试多平台能力降级。

适配器类型：`"sandbox"`　源码：`src/adapter/sandbox/`

启动后本框架起一个本地网页服务（默认 `8800` 端口），浏览器打开即可使用。纯内存模拟，零外部依赖，重启即清空历史。

---

## 安装

```bash
van adapter install sandbox
```

---
## 1. 配置文件

```jsonc
{
  "botId": "Sandbox",
  "type": "sandbox",
  "port": 8800,                    // 网页服务端口（默认 8800）
  "selfName": "沙盒机器人",          // 机器人在网页上显示的昵称（默认 Bot）
  "enable": true
}
```

`selfId` 可选：机器人在场景中的协议 ID（默认 `botId`）。模拟用户的消息 `userId` 不能与 `selfId` 相同（会被内核 ignoreSelf 忽略）。

---

## 2. 网页使用

启动后访问 `http://127.0.0.1:8800`，界面固定三个会话：

- **群聊 · 10001**、**群聊 · 10002**：两个模拟群聊。
- **私聊**：与机器人的单聊（服务端按身份区分，页面合并为一个「私聊」视图）。

右上角可切换 **身份 User1 / User2**，当前会话的所有消息都以该身份发出（插件收到的是不同的 `userId`，方便测试多用户场景）。机器人消息显示为配置的 `selfName`（默认 `Bot`）。

- **消息区**：用户消息与机器人回复实时显示。
- **输入框**：Enter 发送、Shift+Enter 换行。
- **提示**：机器人是否回复取决于插件逻辑（如 keyword 词库匹配、主人指令）。首次测试建议先发 `#设置主人号 User1` 设置主人，再发指令 / 词库内容查看回复。

> 页面每 1 秒轮询一次服务端消息流，机器人回复（经插件处理）自动刷新出来。

---

## 3. 能接收的事件

- 群聊消息 → `group_message`（含群号 + 模拟成员 userId）
- 私聊消息 → `private_message`

事件照常走内核管道：分配 `traceId`、ID 字符串化、填充会话能力集、跑中间件再派发插件，与真实平台完全一致。

---

## 4. 发送 API（插件内统一 `bot.callApi`）

```ts
// 发群消息（落到对应群聊会话的消息流）
await bot.callApi("send_group_msg", { group_id: "10001", message: "你好" })

// 发私聊
await bot.callApi("send_private_msg", { user_id: "10086", message: "你好" })

// 自动判断
await bot.callApi("send_msg", { group_id: "10001", message: "你好" })
```

`message` 支持字符串或消息段数组；图片 / 视频 / markdown / 按钮等段会渲染成对应占位文本显示在网页上。其余 API（如 `get_login_info`）返回模拟成功。

---

## 5. 会话能力

按会话粒度上报能力集（与真实平台一致，方便测试内核降级）：

- 群聊：全消息段 + `canMuteMember` / `canKickMember`
- 私聊：全消息段，无 `canMuteMember` / `canKickMember`

---

## 6. 局限

- 消息历史存内存，框架重启即清空。
- 只模拟消息收发，群成员、禁言、踢人等管理操作不产生真实效果（仅能力标记存在）。
- 页面与服务同进程，仅适合本机 / 内网调试。
